# Design System

## Colors

Original Color Scheme:
Delft Blue - hsl(219, 44%, 21%) / rgb(30, 47, 78) / #1e2f4e
Amber (yellow) - hsl(44, 93%, 54%) / rgb(247, 188, 28) / #f7bc1c
Auburn (red) - hsl(4, 52%, 44%) / rgb(169, 61, 53) / #a93d35
Vista Blue (light blue) - hsl(218, 34%, 60%) / rgb(120, 145, 188) / #7891bc
Davy's Gray (medium gray) - hsl(120, 1%, 29%) / rgb(74, 76, 74) / #4a4c4a
Jet (dark gray) - hsl(90, 2%, 17%) / rgb(44, 45, 43) / #2c2d2b
